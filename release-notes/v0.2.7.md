## Download for Mac

**[Download VRAMpage-MD-v0.2.7-macos.zip](https://github.com/NixMcRetro/VRAMpage-MD/releases/download/v0.2.7/VRAMpage-MD-v0.2.7-macos.zip)** (v0.2.7, complete local-browser package)

1. Download the ZIP and extract it in Finder.
2. Open the **VRAMpage-MD** folder and double-click **START.command**.
3. Your browser opens VRAMpage MD. Select **Load ROM** and choose your own legally usable Mega Drive / Genesis cartridge.
4. Choose **Enable Sound** if you want audio. Keep the launcher's Terminal window open while playing.

**Requirements:** macOS and Python 3. You do **not** need Git, a code editor, Emscripten or manual compilation. This is a browser application launched locally, **not a standalone macOS .app**. It includes no game ROMs.

If macOS blocks the launcher, right-click **START.command** and choose **Open**. If needed, open Terminal, type `bash ` (with a space), drag `START.command` into Terminal and press Return. See the [troubleshooting guide](https://github.com/NixMcRetro/VRAMpage-MD/blob/main/docs/RUNNING-LOCALLY.md).

## What changed

- Add an optional, default-disabled first affected RAM write diagnostic for developer experiments, without storing RAM values.
- Preserve normal gameplay controls, fault models, exact one-write pulse limits and build identification in exports.
- Compare traced and untraced runs reproducibly. The RAM attract-mode divergence milestone remains incomplete.
- Correct an atomic counter-sampling race in the browser regression test; application timing is unchanged.

## Verification and limitations

The release package, checksum, synthetic browser tests (Chromium/Firefox/WebKit) and built-core checks passed in CI. An extracted package was tested with an original synthetic cartridge. This does **not** establish native macOS Firefox, audible sound or commercial-game compatibility.

This is an **experimental, hardware-informed emulator**, not a physically accurate circuit simulation. No commercial game ROM is included. The modified emulator is distributed with corresponding source and upstream non-commercial notices. RAM/VRAM glitches can halt gameplay; Clean restart is the reliable full reset.
