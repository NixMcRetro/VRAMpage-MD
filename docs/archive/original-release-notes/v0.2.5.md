## Run on your Mac

Download **VRAMpage-MD-v0.2.5-macos.zip** below, extract it and double-click **START.command**. Python 3 is required; no Git, Emscripten or compilation is needed. Click **Load ROM** and select your own legally usable Mega Drive cartridge. Enable Sound after loading.

If macOS blocks the launcher: open Terminal, type `bash `, drag START.command into the window and press Return. Keep the launcher window open; Control+C stops the local server. For Firefox, make it your default browser or copy the printed local address into Firefox.

## New: click VRAM legs to disconnect/reconnect

Leave **Leg action** on **Disconnect / reconnect**. Click AD0-AD7 to show a **×** and force that address signal low; click again to reconnect. Multiple legs can be crossed. **Reconnect all [0]** clears contacts. Choose **Bridge two nets** for the original paired-short interaction; presets and momentary keyboard contacts still work.

This is a deterministic stuck-low approximation, not physical chip removal or floating-wire physics. It remains the existing frame-scoped VRAM model; transaction-level VRAM is reserved for v0.3.0 and hardware-informed audio faults for v0.4.0. Faulted writes can persist after reconnecting; Clean restart reboots the cartridge.

Exports now include VRAM mask/bridge state and transition history. RAM and VRAM faults remain exclusive, recovery/reset clears masks, and older cores keep bridge controls with an explanatory fallback. A failed core disconnection no longer loses an armed RAM pulse timer.
