Download **VRAMpage-MD-v0.2.6-macos.zip**, extract it, and open **START.command**. Python 3 is required; no Git, Emscripten or manual compilation is needed. Click **Load ROM** and select your own legally usable Mega Drive cartridge. No game ROMs are bundled.

This incremental RAM-stage release adds application build identification to experiment JSON. Exports include schema version 1, application version and source commit when package metadata is available. Missing, invalid or pending metadata is explicitly unavailable and never blocks gameplay or export. Build identification is not cryptographic proof that files are unmodified.

Includes the existing framebuffer/responsive display fixes, automatic Light/Dark appearance, independent VRAM leg switches and bridges, work-RAM faults, short/write-limited pulses, CPU recovery, clean restart, logging and exports. Fault models are unchanged. Transaction-level VRAM and audio bending remain future milestones.

Automated validation covers native fault models, actual compiled WebAssembly cartridges and Chromium, Firefox and WebKit browser interfaces. These checks do not establish native macOS Firefox, audible output or commercial-game acceptance. The user's earlier v0.2.5 Mac report was qualified: it appears to work as far as they can tell.

The ZIP includes corresponding modified emulator source, runtime files and licence notices. Observe the included third-party non-commercial terms. Previous canonical releases and historical experiment records are preserved.
