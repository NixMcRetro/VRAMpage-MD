Historical source milestone, published retrospectively from its original development commit.

- Integrate work-RAM address/data faults with CPU access, DMA and Z80 bank paths.
- Add fault controls, STOP/HALT monitoring and experiment metadata exports.

Some longword fault accesses were incomplete in this stage and were corrected in v0.2.3. Faulted gameplay may halt or remain static.

This is a source-history release. No prebuilt Mac ZIP is attached, and no fresh runtime validation of this old commit is claimed.

**For a ready-to-run application, [download v0.2.5 for Mac](https://github.com/NixMcRetro/VRAMpage-MD/releases/download/v0.2.5/VRAMpage-MD-v0.2.5-macos.zip).** Extract it and open START.command. Python 3 and your own legally usable cartridge are required.

Source commit: `46d0638e8d7b40b277dcbff57ab205172540f32d`. This commit is part of the preserved main history.
