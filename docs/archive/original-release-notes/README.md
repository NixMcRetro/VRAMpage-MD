# Original GitHub release descriptions

These are archival copies of the **original 12 public release descriptions**
as they appeared before the release-page readability cleanup of 22 October 2026.

Each `v*.md` file preserves its original title, exact description, release
link, publication date and GitHub release ID. The title/body may contain
historical links or older download recommendations that were current at the
time. Do **not** use these copies as installation instructions.

For a working app, visit the [current releases](../../RELEASE-HISTORY.md).
For the simplified current release descriptions, see [release-notes](../../../release-notes/).
Release tag SHAs, package binaries, checksums and original experimental
records are not altered by metadata curation.
