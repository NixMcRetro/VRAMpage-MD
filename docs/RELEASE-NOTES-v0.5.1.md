# VRAMpage MD v0.5.1

The public v0.5.0 release and its assets remain unchanged.

The browser app includes the latest approved original Demo Cart v0.3.5 and
Colour Test, plus Choose Cartridge for switching between them or loading a
local compatible ROM. Region, controller, sound and circuit-bending controls
remain available. User ROM files stay in the browser.

The lightweight static website package retains the playable runtime and curated
cartridges while replacing loose development/source staging with one verified,
version-matched source ZIP and a small Source Code & Licences link. The same ZIP
also accompanies the matching GitHub release. Automatic GitHub source snapshots
are insufficient for generated core modifications. The same-origin source
archive remains the default; GitHub supplies an additional mirror.

The approved cartridge manifest controls builds, identities and attribution.
Browser app version and Demo Cart version remain independent. The original
Demo Cart v0.1 source kit and approved portrait/logo are preserved.

Musashi's exact notice remains inside the WASM as a metadata section. Removing
only that section recovers the previous executable byte for byte. The owner
confirmed non-commercial hobby hosting without monetization. Keep full notices,
LGPL source/rebuild rights and complete corresponding source with the runtime.

Release gates include exact source-to-JS/WASM rebuilding, complete runtime and
approved-ROM checksums, all protected PR/main checks and CodeQL. Website
publication uses a separate reviewed PR and full Jekyll verification.
See the [licence assessment](LICENCE-AUDIT-v0.5.1.md) and [deployment layout and
measured footprint](LIGHTWEIGHT-DEPLOYMENT-v0.5.1.md). GitHub-only source delivery
remains outside this release decision.
