# VRAMpage MD v0.5.1 — Proposed Release

Unpublished review candidate. The public v0.5.0 release and its assets remain
unchanged. No tag, release publication or website deployment is approved.

The proposed static website package retains the current emulator and curated
cartridge selector while replacing hundreds of loose corresponding-source files
with a verified version-matched archive and a small Source Code & Licences link.
The complete source ZIP is also prepared for attachment to the matching GitHub
release; automatic GitHub source snapshots are insufficient for generated core
modifications. The same-origin archive remains the conservative default.

The approved cartridge manifest continues to control Demo Cart and Colour Test
builds, identities and licensing. Local user ROMs remain private. Browser app
version and Demo Cart version are independent.

Before publication, require exact source-to-JS/WASM rebuild verification, complete
runtime/ROM/checksum/link checks, all protected PR/main checks and CodeQL, and
resolution or qualified clarification of the licensing interpretations in the
[audit](LICENCE-AUDIT-v0.5.1.md). See [deployment layout and measured footprint](LIGHTWEIGHT-DEPLOYMENT-v0.5.1.md).
