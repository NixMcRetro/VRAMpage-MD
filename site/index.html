05 / Logic / work RAM

Experimental · 68000 bus model

Bridge one pair of modeled work RAM lines. Apply a fault explicitly; the selectors do not activate it by themselves.

Address-line switches. Click a wire to toggle its × and force that signal low, using Access above. This applies immediately and stays active until reconnected or replaced by another fault. The chip is a conceptual address-bus diagram, not a physical pinout. “Disabled” uses a stuck-low model; a real open wire can float.

CPU recovery disconnects RAM and VRAM faults, leaves PSG/FM faults unchanged, preserves corrupted RAM and may immediately stop again. CPU-only reset leaves other chips running. Use Disconnect all faults to pause and clear each fault domain, or Clean restart for a full reboot.

Quick address pairs: write pulses, using the limit above. Each button applies a pair, then disconnects and attempts resume. These bridge address lines, not particular RAM locations. Affected-write limits release inside the core and expire after one frame. Even one affected write can disrupt later execution; small or recoverable corruption is not guaranteed.

Model limits. This is an experimental transaction model, not an exact physical pin or cycle-level simulation. Read faults affect returned values; write faults alter stored RAM and those changes persist after disconnecting. CPU STOP/HALT indicators report flags only; recovery occurs only through explicit recovery or pulse controls. Data pairs must stay within D0–D7 or D8–D15. Only one fault domain (VRAM or logic/work RAM) is active at a time.

06 / PSG input bridge

D0-D7

Bridge two PSG data inputs. If either requested bit is low, both bridged inputs are forced low on each future PSG write.

The counters aggregate at the PSG write sink and do not identify which CPU initiated a write. Disconnecting changes future writes only. The model does not repair current PSG chip state.

07 / FM register input bridge

D0-D7

Bridge two FM data inputs. The selected low-dominant inputs are applied to each register-address and register-data byte before the chip decodes it.

Counters aggregate at the shared FM write boundary and do not identify which CPU initiated a write. Removing the bridge affects future writes only; it does not repair current chip state. Full sound reset clears the bridge. Z80-only reset preserves the bridge connection and counters.
