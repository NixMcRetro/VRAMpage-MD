Model limits. This is an experimental transaction model, not an exact physical pin or cycle-level simulation. Read faults affect returned values; write faults alter stored RAM and those changes persist after disconnecting. CPU STOP/HALT indicators report flags only; recovery occurs only through explicit recovery or pulse controls. Data pairs must stay within D0–D7 or D8–D15. Only one fault domain (VRAM or logic/work RAM) is active at a time.
