05 / Logic / SRAM (Work RAM)

Experimental · 68000 Bus Model

Bridge one pair of modeled Work RAM lines. Apply a fault explicitly; the selectors do not activate it by themselves.

Work RAM switches. Address/Data wires force selected signals low using Access; data bridges stay within D0–D7 or D8–D15. Writes inhibits the lower (/LWR) or upper (/UWR) byte's future stores, retaining its old contents. Inhibit models an inactive/high write-enable input, not a floating cut. These RAM faults replace one another. The two-byte Model 1 reference and drawing show logical signals; real open wires can float.

CPU recovery disconnects Work RAM, VRAM and Z80 RAM faults, leaves PSG/FM faults unchanged, preserves corrupted RAM and may immediately stop again. CPU-only reset leaves other chips running. The Randomiser-row Force Resume and CPU Recovery switches start On. Two eligible HALT frames trigger one Force Resume; eight further HALT frames permit one CPU-only reset. Turning Force Resume Off skips directly to one CPU reset after two HALT frames. STOP alone does not trigger recovery. A new fault action, toggle change or explicit Resume permits another sequence. This does not detect software loops or a browser locked inside a frame. Disconnect All Faults pauses only when clearing a domain is unavailable, partial or unverified; Clean Restart fully reboots.

No Session Checkpoint

One checkpoint in this session only. Save with faults off and controls released. Restore clears faults and stays paused; press Resume when ready. Clean Restart or loading a cartridge discards the checkpoint. Unsupported cartridge profiles cannot use checkpoints.

Quick address pairs: write pulses, using the limit above. Each button applies a pair, then disconnects and attempts resume. These bridge address lines, not particular RAM locations. Affected-write limits release inside the core and expire after one frame. Even one affected write can disrupt later execution; small or recoverable corruption is not guaranteed.

Model limits. This is an experimental transaction model, not an exact physical pin or cycle-level simulation. Read faults affect returned values; write faults alter stored RAM and those changes persist after disconnecting. CPU STOP/HALT indicators report flags only; automatic HALT recovery follows the switches above. Turn both Off for unassisted experiments. Data pairs must stay within D0–D7 or D8–D15. VRAM and logic/Work RAM faults remain mutually exclusive; the Z80 RAM write bridge is independent.

06 / PSG Input Bridge

D0-D7

Bridge two PSG data inputs. If either requested bit is low, both bridged inputs are forced low on each future PSG write.

The counters aggregate at the PSG write sink and do not identify which CPU initiated a write. Disconnecting changes future writes only. The model does not repair current PSG chip state.

07 / FM Register Input Bridge

D0-D7

Bridge two FM data inputs. The selected low-dominant inputs are applied to each register-address and register-data byte before the chip decodes it.
