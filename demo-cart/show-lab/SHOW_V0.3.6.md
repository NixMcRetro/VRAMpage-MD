# VRAMpage MD Demo Cart v0.3.6

An isolated development candidate for a three-minute original Mega Drive
demoscene show. The approved v0.3.5 source and built-in cartridge manifest
remain unchanged. Goal: six authored scenes, a 120-BPM original YM2612/PSG
score, 50/60-Hz beat synchronization, native A/B/C bending, title and
finale. A copied v0.3.5 builder is the starting point; the current candidate
is not finished or approved for a public release.

Build from source with `python3 demo-cart/show-lab/build_show.py`.
Review only with Genesis Plus GX and captured audio/video. Do not publish,
merge to main, update the default ROM manifest, or deploy McRetro.net
without explicit permission.
